## Configuration

Only Vercel production at https://nurturepath-demo.vercel.app can dispatch. `REHEARSAL_TESTERS_ENABLED=1` exposes the page and enables the gateway. `REHEARSAL_TESTER_CONFIG_HASH` binds the evaluated profile. The existing production Gemini key and Redis connection are reused server side. Signing derives a dedicated child key from the existing limiter secret, which must be at least32 characters. No new secret or tester password is collected. Signed tickets are anonymous session capabilities, not private tester authentication.

## Metadata controls

Run `npm run rehearsal:testers -- config` to inspect the profile and metadata commands offline. Other commands accept a hidden stdin JSON object with the existing store URL and token. Never put credentials in files, arguments, logs or browser bundles. Commands affect only `{nurturepath-rehearsal}:gemini-testers-1:budget`.

`init` creates that namespace once in disabled state, with prepaid mode, zero counters and no expiration. It refuses existing state. `status` reads only configuration, mode, enabled, attempts, reserved cents, issued sessions and pending request. `enable` requires a matching reviewed hash, consistent counters and no pending request. `disable` stops new admission and preserves counters. Requests already sent can still bill. No command resets, refunds, deletes pending state or repairs an uncertain provider outcome automatically.

Metered reservations remain estimates of two cents per admitted request. The prepaid mode has no application dollar stop. It preserves ten admissions and five starts per client pseudonym per minute, one global pending request, two attempts per rehearsal, duplicate rejection and expiring sessions. Duplicate markers expire independently. A malformed output, uncertain settlement or missing usage pauses admission. Investigate the specific pending attempt with observed provider usage before any recovery. Topping up provider credit does not itself reconcile a paused request.

The original public coach and local P3 budgets are separate. Local P3 remains at111 attempts/222 reserved cents following its frozen evaluation. Do not infer current public coach counters from historical records or reset them during tester deployment.

Revise and explicitly send a second round if useful. Select and order up to three questions for the preparation sheet. Print explicitly if desired. Clear or Hide discards practice. Project support uses the existing NurturePath GitHub issue tracker. Omit personal and health information in support requests. Testers are not asked for names, emails or health intake. Use the prototype to assess operation and wording usefulness, and retain its known quality limitations in any demonstration.
